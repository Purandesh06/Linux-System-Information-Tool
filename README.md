#Linux System Information Tool

## Description
A Bash Script that collects and displays essential system information on linux systems.

## Features
- Hostname
- Operating system
- Kernel version
- System uptime
- Disk usage
- Memory usage
- Logged-in users
- Current date and time

## Usage

Clone this repository: 
	git clone https://github.com/Purandesh/Linux-System-information-Tool.git

Navigate into the project:
	cd Linux-System-information-Tool

Run the script:
	bash sysinfo.sh (or) ./sysinfo.sh
